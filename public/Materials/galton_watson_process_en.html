Model Parameters
Parameter λ (Poisson) ?
Poisson distribution
Number of offspring of one particle: \[P(\xi = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0,1,2,\ldots\] Mean \(\mathbb{E}[\xi] = \lambda\), variance \(\mathrm{Var}(\xi) = \lambda\).
Generating function: \(f(s) = e^{\lambda(s-1)}\).

P(extinction) q ?
Extinction probability
The smallest nonnegative root of the equation \(q = f(q)\), where \(f\) is the generating function of the offspring number.
For Poisson: \(f(s) = e^{\lambda(s-1)}\).
For \(\lambda \le 1\): \(q=1\). For \(\lambda > 1\): \(q < 1\) is the unique root of \(q = e^{\lambda(q-1)}\) in \((0,1)\).

The Galton–Watson Process

ℹ️
Reference
The Galton–Watson process is a probabilistic model of a branching population. Each particle independently produces a random number of offspring according to the same distribution. The key parameter is the expected number of offspring \(m = \mathbb{E}[\xi]\). For \(m < 1\) the population is guaranteed to die out, while for \(m > 1\), with probability \(1-q > 0\), it can grow without bound.

Extinct tree

Giant component
The giant-component effect is that, as the generation number grows, the share of descendants coming from some single particle tends to 100%.
