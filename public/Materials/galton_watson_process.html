Параметр λ (Пуассон) ?
Распределение Пуассона
Число потомков одной частицы: \[P(\xi = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0,1,2,\ldots\] Среднее \(\mathbb{E}[\xi] = \lambda\), дисперсия \(\mathrm{Var}(\xi) = \lambda\).
Производящая функция: \(f(s) = e^{\lambda(s-1)}\).

Докритический (m < 1)
P(вырождения) q ?
Вероятность вырождения
Наименьший неотрицательный корень уравнения \(q = f(q)\), где \(f\) — производящая функция числа потомков.
Для Пуассона: \(f(s) = e^{\lambda(s-1)}\).
При \(\lambda \le 1\): \(q=1\). При \(\lambda > 1\): \(q < 1\) — единственный корень \(q = e^{\lambda(q-1)}\) в \((0,1)\).

Процесс Гальтона–Ватсона

ℹ️
Справка
Процесс Гальтона–Ватсона — это вероятностная модель ветвящейся популяции. Каждая частица независимо порождает случайное число потомков согласно одному и тому же распределению. Ключевой параметр — математическое ожидание числа потомков \(m = \mathbb{E}[\xi]\). При \(m < 1\) популяция гарантированно вымирает, при \(m > 1\) с вероятностью \(1-q > 0\) она может расти неограниченно.
