# Комплексные числа: три конструкции одного поля — новый интерактивный материал (1-й из серии «ℂ → конформные отображения»)

## Контекст: серия из трёх материалов

Это первый материал новой мини-серии в категории `analysis`, ведущей от
построения ℂ к конформным отображениям:

1. **Построение ℂ** (этот материал) — три конструкции поля, теорема
   «умножение на комплексное число есть поворотная гомотетия».
2. **Регулярность в ℂ** (не в этом заходе) — комплексная производная,
   регулярная/целая функция, ряд Тейлора, теорема единственности,
   интегральная теорема Коши (дописывается с нуля через формулу Грина),
   $\exp(z)$, формула Эйлера.
3. **Флагман: голоморфность и конформные отображения** (не в этом заходе) —
   регулярность ⟹ локальная линеаризация ⟹ сохранение углов; дробно-линейные
   преобразования; интерактивная графика.

Аксиоматика R сознательно не входит в серию — она уже закрыта
`math_analysis_levels.html` (три формализации: RCF/Вейль/ZFA + таблица
теорем). Материал 1 ссылается на неё, а не дублирует.

## Источник содержания

`~/MATH/Savvateev/250/LevelAlpha.tex` («Введение в настоящую математику»,
книга по мотивам курса «100 уроков математики» А. Савватеева — уже
использовалась для `chasles.html`/`similarities.html`, см.
[[chasles-similarities-content-series]]):

- Глава 12 «Комплексная арифметика и алгебра», §«Алгебра комплексных чисел»,
  строки 6321–6394 — конструкция ℂ как R² с покоординатным сложением и
  умножением $(x,y)(x',y')=(xx'-yy',xy'+x'y)$; мнимая единица, сопряжение,
  модуль.
- Глава 13 «Введение в линейную алгебру», §«Матрицы и комплексные числа»,
  строки 8431–8501 — представление $x+iy\mapsto\begin{pmatrix}x&-y\\y&x
  \end{pmatrix}$; матрица играет роль линейного оператора умножения на
  $z_0=x+iy$; $\det=x^2+y^2$; сопряжение = транспонирование; и главное —
  **доказанная теорема**: преобразование $w=az+b$ (или $w=a\bar z+b$) есть
  подобие плоскости тогда и только тогда, когда $|a|>0$ (строки 8493–8501).
  Там же (строки 8503–8511) — тизер про дробно-линейные преобразования
  $(az+b)/(cz+d)$: окружности и прямые переходят в окружности и прямые —
  задел на материал 3.
- Конструкция $\R[x]/(x^2+1)$ — **не из книги**, стандартная алгебра
  (неприводимость $x^2+1$ над R), добавляется как третья карточка своими
  силами.

Как и с `chasles.html`/`similarities.html`, исходников книги в `homepage` нет
и не будет — только результат (см. [[book-sample-pipeline]],
[[keep-tooling-out-of-deployed-repo]]).

## Явно вне рамок этого материала

- Полное доказательство изоморфизма всех трёх конструкций — только явный
  «словарь соответствий» (раскрывающаяся панель), без формальной проверки
  сохранения операций во всех деталях.
- Гауссовы целые числа (там же в главе 12, но отдельная большая тема) —
  не затрагиваются.
- Комплексная производная, регулярность, ряд Тейлора, $\exp(z)$, формула
  Эйлера — материал 2, не этот.
- Дробно-линейные преобразования и конформность — материал 3, не этот.
  Здесь только теорема про $w=az$ как **линейную** (не дробно-линейную)
  поворотную гомотетию.
- Английская версия — отдельным заходом позже, как и с
  `similarities_en.html`.
- Ссылка вперёд на материал 2 из §4 — не добавляется (материала ещё нет),
  только открытый вопрос в прозе, как было с chasles.html до появления
  similarities.html.

## Структура страницы

Вёрстка, шрифты (EB Garamond + JetBrains Mono), KaTeX 0.16.9 CDN,
CSS-переменные и drag-паттерн — переиспользуются по образцу (не импортом,
файл самодостаточен) из `similarities.html`/`chasles.html`. Стиль карточек
(`.lang-card`, раскрывающаяся панель `axioms-btn`/`showAxioms`) — по образцу
из `math_analysis_levels.html`.

**Title / kicker.** Title тега: «Комплексные числа: три конструкции одного
поля». Kicker: «Математический анализ · Комплексные числа». H1: «Три
конструкции ℂ».

1. **§ Зачем ещё одно число.** Без интерактива. Мотивация: $x^2+1=0$ не имеет
   решений в R (источник: строка 6323 «мотивация: $x^2+1=0$, алгебраизация
   плоскости»). Обратная ссылка на `math_analysis_levels.html`: R полно и
   упорядочено, но не алгебраически замкнуто.

2. **§ Три конструкции одного поля.** Три карточки:
   - **I. R² с арифметикой** — источник строки 6321–6394.
   - **II. Матрицы** $\begin{pmatrix}x&-y\\y&x\end{pmatrix}$ — источник
     строки 8431–8465 ($\det=x^2+y^2$, транспонирование = сопряжение).
   - **III. $\R[x]/(x^2+1)$** — $i:=[x]\bmod(x^2+1)$, $i^2=-1$ по построению.

   Под карточками — свёрнутая по умолчанию панель «это один и тот же
   объект» с явным трёхсторонним словарём (число ↔ матрица ↔ класс вычета).

3. **§ Умножение — это подобие.** Формулировка теоремы (источник, строки
   8493–8501): $w=az$, $a\ne0$ — поворотная гомотетия с центром в нуле,
   коэффициент $|a|$, угол $\arg a$. Явная обратная ссылка на
   `similarities.html` («гомотетия и поворотная гомотетия уже разобраны
   здесь — вот откуда берётся их арифметика»).

   **Интерактивный виджет.** Один драг-хэндл — точка $a$ на комплексной
   плоскости (вектор из начала координат). Фиксированный «флаг»-полигон
   (по образцу `LOCAL_FLAG`/`flagPoints` из `similarities.html`) сидит в
   заданном якоре $z_0\ne0$: полупрозрачный «призрак» — исходное положение,
   сплошной — образ $w=az_0$. Образ считается переиспользованием
   `rotateScalePoint(pt, center, angle, k)` из `similarities.html` **с
   центром, жёстко зафиксированным в $[0,0]$** (в отличие от
   `similarities.html`, где центр $O$ сам перетаскивается) и
   `angle = arg(a)`, `k = |a|`, вычисленными из позиции хэндла $a$.
   KaTeX-панель живо показывает $a=x+iy$, $|a|$, $\arg a$ (в градусах,
   `fmtAngleDeg`-стиль) и численно $w=az_0$ (`fmtCoord`-стиль, округление до
   сотых).

4. **§ Что дальше.** Без интерактива, без ссылки. Открытый вопрос-тизер:
   какие функции $f(z)$ «хорошо» ведут себя относительно такой арифметики —
   дифференцируемы в комплексном смысле в каждой точке.
